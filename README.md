# Лёгкость

Семейный рацион на неделю с локальными ценами Орска, контролем БЖУ и списком покупок. Это статический сайт: он работает с GitHub Pages и открывается напрямую из `index.html`.

## Что внутри

- Орск — регион по умолчанию: Пятёрочка, Магнит, Лента, Светофор, Яндекс Еда и Купер.
- Адреса, условия доставки, ссылки на витрины и локальные JPEG-фотографии магазинов.
- Гибкий рацион: завтрак, обед и ужин настраиваются отдельно для каждого дня.
- БЖУ на порцию, цель 1500 ккал / 90 г белков / 52 г жиров / 150 г углеводов и недельный контроль баланса.
- Подробные рецепты: подготовка, пошаговое приготовление, проверка готовности, советы и подача.
- Локальные аккаунты: пароли хранятся как PBKDF2-SHA256-хеш, данные не отправляются на сервер.
- Основное хранилище — IndexedDB. Если оно недоступно, приложение переходит на localStorage и сообщает об этом. После восстановления IndexedDB данные автоматически переносятся.
- Экспорт и импорт резервной копии, диагностика хранилища и проверка целостности импорта.

## Цены Орска

Снимок цен лежит в двух местах:

- `js/data.js` — встроенный `ORSK_PRICE_SNAPSHOT` (используется при открытии через `file://`);
- `data/prices-orsk.json` — внешний снимок для GitHub Pages (загружается по HTTP).

Формат цен: рубли за килограмм для продуктов с единицей `kg` и рубли за штуку для `pc`. Хлеб, банан и яблоко считаются в граммах. После изменения JSON обновите встроенный снимок, чтобы версия для `file://` оставалась такой же.

Снимок — ориентир, а не онлайн-касса. Публичные страницы доставки нельзя надёжно скрапить с GitHub Pages, поэтому цены обновляются вручную. В приложении есть кнопка «Обновить»: по HTTP она перечитывает `data/prices-orsk.json`, а без сервера объясняет, что используется встроенный снимок.

## Аккаунты и база

Данные хранятся только в браузере:

- `IndexedDB` — аккаунты, профили и сохранённые рационы;
- `localStorage` — резервный режим и текущая сессия;
- резервную копию можно скачать в профиле и импортировать на другом устройстве.

Импорт проверяет формат, уникальность почты, наличие хеша пароля и связи профилей и рационов с аккаунтами. Повреждённый файл не записывается.

## Запуск и публикация

Локально достаточно открыть `index.html`. Для проверки загрузки внешнего снимка цен запустите любой статический сервер в папке проекта:

```powershell
python -m http.server 8765
```

Затем откройте `http://127.0.0.1:8765/`.

Публикация — обычный GitHub Pages из ветки `main`. Сайт: https://bladadd.github.io/legkost/

## Структура

- `index.html` — точка входа;
- `css/styles.css` — тёплая бежевая тема и адаптив 320–1440 px;
- `js/data.js` — магазины, регионы, ингредиенты, блюда, снимок цен;
- `js/app.js` — состояние, генератор рациона, экраны и обработчики;
- `js/db.js` — IndexedDB, резервное хранилище, миграция, пароли, экспорт и импорт;
- `js/recipe-details.js` — подробные рецепты;
- `assets/stores/` — фотографии магазинов, доставки и Орска;
- `assets/CREDITS.md` — авторы и лицензии фотографий.

## Ограничения

- Онлайн-синхронизация с Яндекс Едой и Купером невозможна без официального API или собственного прокси.
- Цены и состав корзины зависят от магазина, времени и региона; итоговую сумму подтверждайте в приложении доставки.
- Фотографии магазинов — иллюстративные, а не снимки конкретных точек Орска.
