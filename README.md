# Лёгкость

Семейный рацион на неделю с локальными ценами Орска, контролем БЖУ, списком покупок и локальным ИИ-ассистентом. Это статический сайт на GitHub Pages, который открывается напрямую из `index.html` и устанавливается как PWA-приложение.

## Что внутри

- **Орск — регион по умолчанию**: Пятёрочка, Магнит, Лента, Светофор, Яндекс Еда и Купер с адресами, условиями доставки, ссылками и локальными JPEG-фото.
- **Гибкий рацион**: завтрак, обед и ужин настраиваются отдельно для каждого дня недели. Режимы «для себя» / «на всех», копирование и очистка дня.
- **БЖУ и бюджет**: цель 1500 ккал / 90 г белков / 52 г жиров / 150 г углеводов, бюджет по умолчанию 6000 ₽ на неделю. Недельный и дневной контроль макросов с бейджем «✓ в балансе».
- **Реальные упаковки**: список покупок считает целые пачки, бутылки и штуки, а не граммы. Есть чекбокс «уже есть дома» — такие продукты вычитаются из суммы.
- **Экран «Сегодня»**: следующий приём пищи, стоимость дня, БЖУ, быстрые покупки и кнопка «Приготовить».
- **Подробные рецепты**: подготовка, пошаговое приготовление, проверка готовности, советы и подача для всех блюд.
- **Свои рецепты**: добавьте собственные блюда с ингредиентами, БЖУ, шагами и эмодзи — они участвуют в генерации наравне с встроенными.
- **Локальный ИИ-ассистент**: через Ollama на вашем ноуте (шлюз `server/ai-gateway.mjs`). Помогает сделать рацион дешевле, заменить блюдо, разобрать список покупок, подобрать рецепт. Данные не уходят с устройства.
- **Локальные аккаунты**: пароли хранятся как PBKDF2-SHA256-хеш, данные не отправляются на сервер.
- **Основное хранилище — IndexedDB**, резервное — localStorage. Авто-миграция, диагностика, экспорт и импорт резервных копий.
- **PWA**: веб-манифест, service worker, установка на домашний экран, офлайн-режим, ярлыки «Сегодня» и «Покупки».
- **Адаптив**: 320–1440 px без горизонтального overflow.

## Цены Орска

Снимок цен лежит в двух местах:

- `js/data.js` — встроенный `ORSK_PRICE_SNAPSHOT` (при открытии через `file://`);
- `data/prices-orsk.json` — внешний снимок для GitHub Pages (загружается по HTTP).

Формат цен: рубли за килограмм для продуктов с единицей `kg` и рубли за штуку для `pc`. Хлеб, банан и яблоко считаются в граммах.

Снимок — ориентир, а не онлайн-касса. Публичные страницы доставки нельзя надёжно скрапить с GitHub Pages, поэтому цены обновляются вручную. В приложении есть кнопка «Обновить».

## Запуск локально

Достаточно открыть `index.html`. Для проверки загрузки внешнего снимка цен и работы PWA запустите любой статический сервер:

```powershell
python -m http.server 8765
```

Затем откройте `http://127.0.0.1:8765/`.

## Локальный ИИ-ассистент

Ассистент работает через локальный шлюз к Ollama. Он не обязателен — если шлюз недоступен, приложение работает как раньше.

1. Установите [Ollama](https://ollama.com/) и загрузите модель:
   ```powershell
   ollama pull qwen3:4b
   ```
2. Запустите шлюз:
   ```powershell
   cd server
   start-ai.bat
   ```
3. Откройте сайт на `http://127.0.0.1:8765/` — появится кнопка «Помощник».

Шлюз настраивается через переменные окружения: `OLLAMA_URL`, `PORT`, `ALLOW_ORIGIN`, `AI_MODEL`, `AI_RATE_LIMIT_SEC`.

## Структура

- `index.html` — точка входа, манифест PWA, service worker;
- `manifest.webmanifest` — манифест для установки как приложения;
- `sw.js` — service worker (офлайн, кэширование);
- `css/styles.css` — тёплая бежевая тема и адаптив 320–1440 px;
- `js/data.js` — магазины, регионы, ингредиенты, упаковки, блюда, снимок цен;
- `js/app.js` — состояние, генератор, экраны, БЖУ, цены, карта, кастомные рецепты, мост ИИ;
- `js/assistant.js` — панель ИИ-ассистента, контекст, быстрые действия;
- `js/db.js` — IndexedDB, резервное хранилище, миграция, пароли, экспорт и импорт;
- `js/recipe-details.js` — подробные рецепты встроенных блюд;
- `server/ai-gateway.mjs` — локальный шлюз к Ollama;
- `server/start-ai.bat` — скрипт запуска шлюза;
- `assets/stores/` — фотографии магазинов, доставки и Орска;
- `assets/food/dishes/` — фотографии блюд;
- `assets/avatars/` — аватары профиля;
- `assets/CREDITS.md` — авторы и лицензии фотографий.

## Ограничения

- Онлайн-синхронизация с Яндекс Едой и Купером невозможна без официального API или собственного прокси.
- Цены и состав корзины зависят от магазина, времени и региона; итоговую сумму подтверждайте в приложении доставки.
- Фотографии магазинов — иллюстративные, а не снимки конкретных точек Орска.
- ИИ-ассистент не считает бюджет и БЖУ — это делает обычный код приложения. ИИ только предлагает действия, которые пользователь подтверждает.
