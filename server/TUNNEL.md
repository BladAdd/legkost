# Публичный доступ к шлюзу ИИ (Cloudflare Tunnel)

Чтобы ИИ-ассистент работал для всех посетителей `https://bladadd.github.io/legkost/`, шлюз должен быть доступен из интернета. Ноутбук должен быть включён и подключён к сети.

## 1. Установи cloudflared

Скачай с https://developers.cloudflare.com/cloudflare-one/connections/connect-apps/install-and-setup/installation

## 2. Запусти шлюз

```powershell
cd server
start-ai.bat
```

Шлюз стартует на `http://0.0.0.0:3001`, принимает запросы только с `https://bladadd.github.io`.

## 3. Создай туннель

```powershell
cloudflared tunnel --url http://localhost:3001
```

Получишь URL вида `https://абвгд.trycloudflare.com`.

## 4. Укажи URL в приложении

Открой сайт, зайди в **Профиль → ИИ-ассистент**, введи полученный URL. Он сохранится в локальном хранилище браузера.

Каждый посетитель может указать свой URL шлюза. Если не указать — помощник будет недоступен (приложение работает как обычно).

## Важное

- **Ноутбук должен быть включён** — иначе шлюз недоступен.
- **GTX 1050 Ti (4 ГБ VRAM)** — модель `qwen3:4b` работает, но ответ идёт ~30–40 с. Если несколько пользователей одновременно — запросы выстраиваются в очередь.
- **Бесплатный туннель TryCloudflare** — URL меняется при перезапуске `cloudflared`. Для постоянного URL нужен аккаунт Cloudflare и свой домен.
- **Безопасность** — можно задать `AI_KEY` в `start-ai.bat`, тогда посетители должны передавать заголовок `X-AI-Key`.

## Альтернатива — свой сервер

Если нужно 24/7 без ноутбука — разверни `server/ai-gateway.mjs` на VPS (Railway, Render, DigitalOcean и т.д.) и укажи его URL в профиле.
