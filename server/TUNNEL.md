# Публичный доступ к своему шлюзу ИИ (Cloudflare Tunnel)

ИИ-ассистент уже работает у всех посетителей `https://bladadd.github.io/legkost/` в облачном режиме — без ключей, без ноутбука и без этого туннеля. Этот документ нужен, только если хочется отвечать через **свой** ПК (приватность, без лимита 1 ответ / 30 секунд).

Ноутбук должен быть включён и подключён к сети.

## 1. Установи cloudflared

Скачай с https://developers.cloudflare.com/cloudflare-one/connections/connect-apps/install-and-setup/installation

## 2. Запусти шлюз

```powershell
cd server
start-ai.bat
```

Шлюз стартует на `http://0.0.0.0:3001`. `ALLOW_ORIGIN` по умолчанию — `https://bladadd.github.io,http://localhost:8765,http://127.0.0.1:8765`.

## 3. Создай туннель

```powershell
cloudflared tunnel --url http://localhost:3001
```

Получишь URL вида `https://абвгд.trycloudflare.com`.

## 4. Укажи URL в приложении

Открой сайт, зайди в **Профиль → ИИ-ассистент**, введи полученный URL. Он сохранится в локальном хранилище браузера, и панель переключится в режим «Свой ПК».

## Важное

- **Ноутбук должен быть включён** — иначе шлюз недоступен (помощник вернётся к облаку или офлайн-ответу).
- **GTX 1050 Ti (4 ГБ VRAM)** — `qwen2.5:3b` отвечает за 1–5 с. `qwen3:4b` работает, но тратит время на рассуждения и обрезается по лимиту токенов — не используй его для чата.
- **Бесплатный туннель TryCloudflare** — URL меняется при перезапуске `cloudflared`. Для постоянного URL нужен аккаунт Cloudflare и свой домен.
- **Безопасность** — можно задать `AI_KEY` в `start-ai.bat`, тогда клиент должен передавать заголовок `X-AI-Key`.

## Альтернатива — Cloudflare Worker + Groq

`server/cloudflare-worker.js` — прокси к бесплатному Groq. Нужны аккаунт Cloudflare, Worker и секрет `GROQ_API_KEY`. Тогда ИИ работает 24/7 без ноутбука и без лимита 30 секунд.

## Альтернатива — свой сервер

Разверни `server/ai-gateway.mjs` на VPS (Railway, Render, DigitalOcean и т.д.) и укажи его URL в профиле.
